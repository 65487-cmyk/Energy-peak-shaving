# Energy-peak-shaving.
An end-to-end solar peak shaving design project featuring an interactive Streamlit dashboard for daily and annual peak energy analysis,
integrated with PVsyst for detailed solar array modeling and performance simulation
# Project Overview
This project delivers a data-driven solar peak shaving solution without battery storage. It bridges data analytics and industrial solar design using a two-stage workflow:

1. **Data Analysis (Streamlit):** An interactive dashboard used to analyze facility load profiles and calculate the exact daily and annual peak energy required for shaving.
2. **System Simulation (PVsyst):** A professional solar system design engineered to match those peak shading targets and simulate real-world energy yield.

## Tech Stack
* **Python & Streamlit:** For load profile data visualization and peak calculations.
* **PVsyst:** For solar array sizing, shading analysis, and generation modeling.
